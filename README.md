# ChordSense

Ear training for ADHD brains. Listen to a chord — is it happy or sad?

No instrument. No music theory. Just your ears.

## How to play

1. Press **Play** to hear a chord
2. Guess **Happy** or **Sad**
3. 10 rounds. Instant feedback.

## Run it

Download and open `index.html` in any browser. That's it.

## Built with

HTML, CSS, JavaScript, Web Audio API.
